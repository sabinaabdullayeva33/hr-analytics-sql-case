Bu layihə PostgreSQL mühitində insan resursları (HR) verilənləri üzərində biznes təhlillərinin aparılması, əməkhaqqı dinamikasının izlənməsi və verilənlərin tamlığının (Data Quality) yoxlanılması məqsədilə hazırlanmışdır.

---

## 📁 Layihə Faylları
* 01_schema_and_data.sql — Cədvəl strukturları və test məlumatları.
* 02_hr_analysis_queries.sql — Analiz və audit sorğuları.
